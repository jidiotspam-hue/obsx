Privacy Policy

Effective Date: November 1, 2026 · Version 2.3.2

OBSX Security (“OBSX”, “we”, “our”, or “us”) is an open-source client integrity attestation and anti-automation platform. We believe security should never come at the expense of user privacy. Unlike commercial CAPTCHA and fingerprinting networks, OBSX is built on a privacy-first, cryptographic paradigm that does not track users across websites, build behavioral advertising profiles, or store personal identifiers.

Summary of Core Privacy Guarantees

  • Zero Cross-Site Tracking: We never set third-party tracking cookies or store cross-site advertising IDs.
  • No Biometric Storage: Neuromuscular micro-tremor and kinematic trajectory signals are evaluated ephemerally in volatile memory and immediately discarded.
  • Cryptographic Proof-of-Work: Client legitimacy is verified by hardware work puzzles (SHA-256 micro-challenges) solved locally in the user's browser, not by invasive identity harvesting.
  • Subnet-Truncated IP Processing: Client IP addresses are processed in memory and aggregated by subnet (/24 IPv4, /48 IPv6) solely for anti-DDoS challenge escalation.

1. Information We Collect and Process

OBSX processes technical signals strictly to distinguish legitimate human web browsers from automated botnets, credential stuffers, and unauthorized API scrapers:

  • Ephemeral Cryptographic Nonces: Random challenge tokens solved client-side via native Web Crypto. Nonces expire within 300 seconds and are permanently invalidated once spent.
  • Hardware Execution Indicators: Ephemeral GPU pipeline rasterization signatures to confirm an active display driver (distinguishing physical displays from headless software emulators like llvmpipe). These 32-bit hashes contain zero hardware serial numbers.
  • Network Level Data: Request IP addresses and standard HTTP request headers, utilized exclusively for rate-limiting and subnet-level abuse prevention.
  • Developer Account Data: For registered platform developers using the dashboard, we retain email addresses for passwordless authentication (OTP verification) and secret key management.

2. Legal Basis for Processing (GDPR Article 6)

For users located in the European Economic Area (EEA) and United Kingdom (UK), our processing of technical telemetry is lawful under Article 6(1)(f) GDPR (Legitimate Interests): protecting web application infrastructure, safeguarding user accounts from brute-force takeover, and preventing malicious denial-of-service traffic.

3. Data Retention and Discard Policy

All client session tokens and behavioral verification markers are stored in short-lived memory structures with a maximum Time-To-Live (TTL) of 300 seconds (5 minutes). Once a verification token is consumed or expired, it is atomically deleted. We do not maintain historical logs of individual visitor mouse movements or keystroke data.

4. Third-Party Disclosures & International Transfers

OBSX Security does not sell, rent, monetize, or disclose visitor telemetry to third-party data brokers, advertising networks, or analytics aggregators. In self-hosted or on-premises deployments, all telemetry remains strictly within your enterprise perimeter.

5. Your Rights (GDPR & CCPA/CPRA)

Under applicable international privacy regulations, you have the right to:

  • Request access to or deletion of developer account credentials.
  • Object to processing based on legitimate interests.
  • Inquire about the technical parameters of automated threat mitigation.

Because OBSX does not track end-user browsing identities across websites, we cannot correlate anonymous client verification tokens to individual human identities.

6. Open-Source Transparency

In accordance with Kerckhoffs's Principle, all code governing OBSX client signal collection and server verification is open-source and auditable on GitHub at github.com/jidiotspam-hue/obsx.

7. Contact and Security Inquiries

For privacy questions, vulnerability disclosures, or Data Processing Agreement (DPA) requests for enterprise deployments, please contact our security team at security@obsx.tech or official@obsx.tech.
