OBSX Integration & API Guide

How to integrate OBSX client attestation, solve ephemeral micro-proof-of-work puzzles, and verify incoming requests deterministically on your server.

1. Browser Client Installation Zero Runtime Dependencies

Include the official lightweight client SDK in your page <head> before other scripts execute: 

<script src="https://obsx.tech/obsx.min.js" data-obsx-site="pk_YOUR_SITE_KEY"></script>

Zero-JS Form Protection (Fastest)

Add data-obsx-protect to any HTML form to inject hidden obsx-token and obsx-nonce inputs automatically on submit: 

<script src="https://obsx.tech/obsx.min.js" data-obsx-site="pk_YOUR_SITE_KEY" defer></script>

<form action="/api/checkout" method="POST" data-obsx-protect>
  <input type="email" name="email" required />
  <button type="submit">Complete Order</button>
</form>

Programmatic SPA Verification

When a sensitive user action is triggered (checkout, prompt generation, voucher claim, or sign-up): 

// Automatically harvests biometric entropy and solves the SHA-256 micro-PoW (~15ms)
async function handleCheckout(cartItems) {
  const { token, nonce } = await OBSX.getAttestation();

  // Submit single-use token & PoW nonce with your request (or use await OBSX.seal({ items: cartItems }))
  const response = await fetch('/api/checkout', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ token, nonce, items: cartItems })

  return response.json();
}
2. Server-Side Verification Gate Zero External Dependencies

Verify the client session token and single-use replay nonce before processing business logic: 

// Express 1-Line Middleware
const obsx = require('obsx-security');

app.post('/api/checkout', obsx.middleware({ secretKey: process.env.OBSX_SECRET_KEY }), async (req, res) => {
  // Attestation passed (req.obsx holds { ok, verdict, risk, reasons })

  res.json({ ok: true, orderId: order.id });

Standalone Direct HTTP Verification

If you are using Python, Go, Ruby, or Rust, verify directly via HTTPS against https://obsx.tech/api/v1/verify (or your self-hosted node): 

curl -X POST https://obsx.tech/api/v1/verify \
  -H "Authorization: Bearer sk_YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "token": "CLIENT_TOKEN",
    "nonce": "POW_NONCE"
  }'

# Response:
# { "ok": true, "verdict": "accept", "allowed": true, "risk": 0, "reasons": [] }

Core mathematical properties enforced by the OBSX Protocol:

  defer></script>

<!-- Existing .g-recaptcha containers & grecaptcha.ready/execute() keep working -->

// Backend (Next.js App Router / Web Request / Express):
import { verifyRequest } from 'obsx-security';

export async function POST(request: Request) {
  const verdict = await verifyRequest(request, { secretKey: process.env.OBSX_SECRET_KEY! });
  if (!verdict.allowed) return Response.json({ ok: false, reasons: verdict.reasons }, { status: 403 });
  return Response.json({ ok: true, risk: verdict.risk });
}
