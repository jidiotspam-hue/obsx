// 01 Architecture

Proof-of-work attestation meets zero-dependency verification.

Traditional anti-bot scripts blindly accept whatever JSON telemetry the client submits. OBSX challenges client compute, verifies hardware bindings, and seals every request with single-use cryptographic tokens.

01 / POW

Cryptographic Micro-PoW

Every session is challenged with an ephemeral SHA-256 micro-puzzle. Solved in ~15ms via Web Crypto; prevents automated botnets from flooding requests for free.

02 / ZERO TRUST

Mandatory Attestation

Unlike legacy scripts where empty JSON payloads {} pass at risk 0, OBSX treats missing signals as immediate hard rejections.

03 / TAMPER AUDIT

Descriptor-Level Probing

Inspects property descriptors and native Web IDL accessors to detect .bind() hooks, Proxy traps, and web proxy unblockers.

04 / ENTROPY

Kinematic Jerk Analysis

Evaluates human pointer curvature (minimizing d³x/dt³) and keystroke variance to catch synthetic linear trajectories and robotic cadences.

const { verifyToken } = require('obsx-security');

app.post('/api/action', async (req, res) => {
  const { token, data } = req.body;

  // Zero-dependency HMAC and replay verification (<1ms)
  const result = await verifyToken(token, {
    secret: process.env.OBSX_SECRET,
    clientIp: req.ip
  });

  if (result.verdict === 'reject') {
    return res.status(403).json({ ok: false, error: 'gate_rejected', reasons: result.reasons });
  }

  // Action verified — proceed with business logic
  res.json({ ok: true, status: 'success' });
});
import { NextResponse } from 'next/server';
import { verifyToken } from 'obsx-security';

export async function POST(request: Request) {
  const { token, data } = await request.json();
  const clientIp = request.headers.get('x-forwarded-for') || '127.0.0.1';

  const result = await verifyToken(token, {
    secret: process.env.OBSX_SECRET!,
    clientIp
  });

  if (result.verdict === 'reject') {
    return NextResponse.json({ ok: false, reasons: result.reasons }, { status: 403 });
  }

  return NextResponse.json({ ok: true });
}
from fastapi import FastAPI, HTTPException, Request
from obsx import verify_token
import os

app = FastAPI()

@app.post("/api/action")
async def handle_action(request: Request):
    body = await request.json()
    verdict = verify_token(
        token=body.get("token"),
        secret=os.environ["OBSX_SECRET"],
        client_ip=request.client.host
    )
    if verdict["verdict"] == "reject":
        raise HTTPException(status_code=403, detail=verdict["reasons"])
    return {"ok": True}

// 06 Trust & Philosophy

Built for public open-source scrutiny.

Auguste Kerckhoffs stated in 1883 that a cryptosystem must remain secure even if everything about the system is public knowledge. OBSX does not rely on hidden obfuscated code—it relies on mathematics, physical inertia, and cryptographic invariants.

GUARANTEE 01

100% Mathematical Proofs

Even if an attacker studies our full solver code, the computational cost of the SHA-256 micro-puzzle must still be paid by the hardware.

GUARANTEE 02

Zero External Dependencies

Powered entirely by native Web Crypto in the browser and Node.js crypto on the server. Zero third-party analytics, zero external latency.

GUARANTEE 03

Privacy-First Architecture

No tracking cookies, no cross-site user profiles, and no biometric data leaves the client. Only cryptographic risk proofs and session tokens are submitted.
