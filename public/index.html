// 01 Architecture

Proof-of-work attestation meets zero-dependency verification.

Traditional anti-bot scripts blindly accept whatever JSON telemetry the client submits. OBSX challenges client compute, verifies hardware bindings, and seals every request with single-use cryptographic tokens.

01 / POW

Cryptographic Micro-PoW

Every session is challenged with an ephemeral SHA-256 micro-puzzle (typically ~15ms on modern browsers via Web Crypto), imposing compute cost on automated traffic.

02 / ZERO TRUST

Mandatory Attestation

Unlike legacy scripts where empty JSON payloads {} pass at risk 0, OBSX treats missing signals as immediate hard rejections.

03 / TAMPER AUDIT

Descriptor-Level Probing

Inspects property descriptors and native Web IDL accessors to detect .bind() hooks, Proxy traps, and web proxy unblockers.

04 / ENTROPY

Kinematic Jerk Analysis

Evaluates human pointer curvature (minimizing d³x/dt³) and keystroke variance to catch synthetic linear trajectories and robotic cadences.

import { NextResponse } from 'next/server';
import { verifyToken } from 'obsx-security';

export async function POST(request: Request) {
  const body = await request.json();

  const result = await verifyToken(body, {
    secretKey: process.env.OBSX_SECRET_KEY!,
    clientUa: request.headers.get('user-agent') || undefined
  });

  if (!result.allowed) {
    return NextResponse.json({ ok: false, reasons: result.reasons }, { status: 403 });
  }

  return NextResponse.json({ ok: true });
}
from fastapi import FastAPI, HTTPException, Request
import httpx
import os

app = FastAPI()

@app.post("/api/action")
async def handle_action(request: Request):
    body = await request.json()
    async with httpx.AsyncClient(timeout=5.0) as client:
        resp = await client.post(
            "https://obsx.tech/api/v1/verify",
            headers={
                "Authorization": f"Bearer {os.environ['OBSX_SECRET_KEY']}",
                "X-OBSX-Client-UA": request.headers.get("user-agent", ""),
            },
            json={
                "token": body.get("token") or body.get("obsx-token"),
                "nonce": body.get("nonce") or body.get("obsx-nonce"),
            },
        )
    verdict = resp.json() if resp.status_code == 200 else {"allowed": False, "reasons": ["verify_failed"]}
    if not verdict.get("allowed"):
        raise HTTPException(status_code=403, detail=verdict.get("reasons", []))
    return {"ok": True}

// 06 Trust & Philosophy

Built for transparent cryptographic verification.

Auguste Kerckhoffs stated in 1883 that a cryptosystem must remain secure even if everything about the system is public knowledge. OBSX does not rely on hidden obfuscated code—it relies on mathematics, physical inertia, and cryptographic invariants.

PILLAR 01

Cryptographic Work Proofs

Knowing the solver code does not let a client skip the computational cost of solving the ephemeral SHA-256 micro-puzzle.

PILLAR 02

Zero External Dependencies

Powered by native Web Crypto in the browser and Node.js crypto on the server, with no third-party font or analytics requests.

PILLAR 03

Privacy-First Processing

No tracking cookies or cross-site profiles; ephemeral session interaction telemetry is deleted immediately upon verify() completion.
